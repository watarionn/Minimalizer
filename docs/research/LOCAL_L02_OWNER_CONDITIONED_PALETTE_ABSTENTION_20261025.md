# Lane A L02: owner-conditioned palette abstention (2026-10-25)

**Draft research candidate, not semantic repair approval.** This branch is based on main `1f495bd5d62096c5fae576058c9939ccccf317ab`. The existing PR #430 uses a pooled RGB/LAB palette trained from class32+AnimeSeg generic-clothes pixels belonging to **either** frozen owner. That permits jacket-colored additions to be justified by the coat palette (or vice versa), even when the target owner has no corresponding color evidence. This is a source-only *owner attribution risk*, not proof of the exact 17 H08 arm false positives.

The new filter accepts the already-frozen #430 source-only candidate and can **only abstain on newly added owner pixels**. It learns separate 8-center LAB palettes from each owner's own frozen class32+generic-clothes observations (minimum 1,024 pixels, 95th percentile and maximum LAB distance 25, matching the preexisting palette policy). A candidate pixel must match its **own** palette and, if both are available, be strictly closer to that palette than to the competing owner's palette. Equal distances abstain. Insufficient own training evidence abstains. After filtering, detached additions are discarded and existing 4/8 frozen-component identity and no-new-cross-owner-contact gates are reused. Frozen owner pixels, source alpha, model class observations and human-reviewed labels are not modified.

**Source-free isolated negative tests:** 6 passed in the development container (numpy/scipy/opencv/pytest). They cover wrong-owner color borrowing, correct-owner retention, equal-palette ambiguity, frozen-owner reassignment, alpha bounds and deterministic replay. The local test harness used a functionally equivalent shim for the existing cross-owner edge verifier because the complete repository checkout was not available in that container. This is **not** full repository CI or an authenticated signed-image replay.

**Known signed quality frontier, inherited from PR #430 (not remeasured here):** H04 known FP 4,423px; H06 underlayer FP 1,077px and outerwear FN 20,803px; H08 outerwear FN 13,198px and new arm FP 17px. PR #430's H08 gain of 5,583 true sleeve pixels is an earlier result and is not counted again. This stricter filter might reject valid sleeve pixels. No P0/P1 improvement can be claimed without a signed replay and unknown-aware postscore.
