# MinimalizerPublic StructuralRecovery P0 Stage6 — signed-face blanking policy (2026-10-11)

**Source/SHA and synthetic contract PASS / final face policy Golden HOLD.** Isolated module `web/static/public-signed-face-blank-p0.mjs`, tests `tests/js/test_public_signed_face_blank_p0.mjs`. It accepts only authenticated original-source RGBA, frozen candidate RGBA and historically signed face 0/255 mask. Pixel color is the exact original source-RGB triplet nearest the *skin candidate median* inside signed face, provided sufficient real skin evidence exists; never an invented RGB. Every pixel inside the signed face is a single flat source sample; no new eyes, iris, eyebrows, nose or mouth are drawn. Outside the signed face and all alpha values remain byte-identical to the input candidate. Unsupported skin masks, transparency, wrong hash, malformed/oversize face, insufficient source observations fail closed. This does not train or use any generative model.

Verified on both **original, independent SHA-pinned source photos**, Stage5 frozen opt-in preview, and Stage04 original face masks. The 4,937-pixel GC001 face uses an actually observed `[252,237,232]` RGB; 4,052-pixel Raden face uses `[252,237,236]`. Replayed twice with matching bytes and audit, inputs never mutated. **Face skin paint increases image-wide RGB error** because the input contains face hair, eyes and shading intentionally removed for compliance, so do not use naive MSE as this gate. Visually a blank face is policy-conformant **within its mask**, but some former eye-like source-color remnants **outside** the signed mask remain. `outsideSignedFaceMicrofeatureSuppressionVerified` is explicitly false. Human checking of the face/hair boundary and optional independently authorized larger exclusion regions is mandatory.

Stage6 does not fix bow, ribbon, oversized color fragments, silhouette, arm/hand distinctions or Stage8 source ring vertex budgets. Dedicated face/garment source boundary ownership and actual browser route are still HOLD. Neither Local Minimalizer nor normal Public product behavior changed. Do not merge/release this research without separate Golden, true browser Chrome/iPhone gates, rollback and license checks.
