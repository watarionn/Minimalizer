# Golden Comparison Production Bridge

Status: IMPLEMENTED / DEFAULT OFF

The production bridge is the first runtime-facing connection from the frozen Golden Comparison rules into candidate preparation.

Flow:
semantic manifest + feature evidence -> G3 Feature Survival -> G4 Semantic Budget -> G5 Geometry Plan -> G7 Guarded DiffMin contract.

The bridge does not use a Golden raster as production input. It is generic and has no GC001 character names, colors, or coordinates. It is default OFF and must be explicitly enabled. A G3 hard failure blocks candidate authorization before budgeting or geometry authorship. DiffMin remains separately default OFF.

This milestone deliberately prepares and authorizes semantic geometry rather than silently replacing the existing ProductionPipeline renderer. Concrete fitting/rendering must consume the authorized geometry contract in the next step, then the sealed G8 blind corpus can be executed without changing G2-G7 rules.
